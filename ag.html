Диагноз АГ устанавливают по результатам трёхкратного измерения АД в положении сидя — используют среднее из двух последних измерений. Термин «гипертоническая болезнь» (ГБ) >90% всех форм АГ.

2. Обследования, показанные ВСЕМ пациентам с АГ

Лабораторная диагностика не нужна для установления диагноза АГ, но обязательна для исключения вторичных форм, выявления поражения органов-мишеней (ПОМ), оценки сердечно-сосудистого риска (ССР) и сопутствующей патологии.

4. При подозрении на вторичную АГ — поиск причин

Заподозрить при: АГ 2–3 степени в молодом возрасте (<40 лет), резистентной АГ (не контролируется на 3 препаратах, включая диуретик), злокачественном течении, внезапном начале, гипокалиемии.

Стартовая стратегия (КР 2024)

  • Комбинированная терапия — всем, кроме низкого риска с АД <150/90, пациентов ≥80 лет, пациентов с ССА
  • Предпочтительно фиксированные комбинации
  • Предпочтительная комбинация: иАПФ/БРА + АК или диуретик
  • При АД >150/90 и высоком риске — старт сразу с 2 препаратов

7. Обоснования для ДМС / страховой — формулировки из КР

Записывать в карте обоснование каждого назначения — так страховая не задаёт вопросов и не отклоняет оплату.

ОАК, ОАМ, биохимия, ЭКГ: «С целью исключения вторичной АГ, выявления поражения органов-мишеней, оценки сердечно-сосудистого риска и сопутствующей патологии» (п. 2.7–2.8 КР 2024).
Липидограмма: «Для стратификации риска и выявления нарушений липидного обмена» (п. 2.7 КР, УУР B).
Креатинин + СКФ: «Для выявления ХБП и оценки сердечно-сосудистого риска» (п. 2.7 КР, УУР B, класс I).
Альбумин/креатинин мочи: «Для выявления заболеваний почек и оценки сердечно-сосудистого риска» (п. 2.7 КР, УУР B, класс I).
ЭхоКГ: «При изменениях на ЭКГ / симптомах дисфункции ЛЖ — для выявления гипертрофии ЛЖ» (п. 2.8 КР, УУР B, класс I).
ДС БЦА: «Для выявления атеросклеротических бляшек/стенозов ВСА — высокий ССР, возраст >40/>50 лет» (п. 2.8 КР, УУР B, класс I).
Направление к офтальмологу: «АГ 2–3 степени + СД — для выявления гипертонической ретинопатии» (п. 2.8 КР, УУР C, класс I).
Направление к нефрологу: «ХБП с СКФ <30 мл/мин/1,73 м² и/или альбуминурия А3–А4» (п. 2.4 КР).
Альдостерон/ренин (АРС): «Для исключения первичного гиперальдостеронизма — резистентная АГ, гипокалиемия» (п. 2.7 КР).
Комбинированная терапия: «Стартовая терапия — комбинация иАПФ/БРА + АК/диуретик, предпочтительно фиксированная, для улучшения приверженности» (п. 3.4.1 КР, УУР A, класс I).
